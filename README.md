# Playwright QA Automation Practice

This repository documents my journey learning QA Automation using Playwright and JavaScript.

## Technologies
- Playwright
- JavaScript
- Node.js
- Visual Studio Code
- Git & GitHub

## Test Scenarios

Automated tests using [Sauce Demo](https://www.saucedemo.com/):

- Successful login
- Invalid login credentials
- Add a product to the shopping cart
- Remove a product from the shopping cart

## How to Run Tests

Install dependencies:

```bash
npm install
```

Install Playwright browsers:

```bash
npx playwright install
```

Run tests using Chromium:

```bash
npx playwright test --project=chromium
```
